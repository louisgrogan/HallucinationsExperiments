# HallucinationsExperiments
Repository for Team Psi's Hallucinations Experiments Code

## 🛠️ Installation and Usage

1. Clone the repository:
```bash
git clone [your-repository-url]
cd to root
```

2. Create and activate a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Set up environment variables:
   - Fill in your API keys and configuration in .venv

5. Run test_extractor.ipynb to run experiments

6. View results generated into output files in root folder:
  - In Text Format: Results.txt
  - In CSV Format: results.csv
